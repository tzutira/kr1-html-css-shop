# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница.
- `catalog.html` — каталог товаров.
- `product.html` — страница товара; параметр `?product=1`, от `1` до `6` выбирает товар.
- `order.html` — отдельная форма заявки.
- `contacts.html` — контактная информация.
- `sitemap.xml` — карта сайта с адресами пяти страниц GitHub Pages.
- `css/style.css` — общие стили сайта.
- `js/main.js` — логика формы, модального окна и валидации.
- `images/` — изображения проекта.
- `README.md` — описание проекта.
- `.gitignore` — правила исключения файлов из Git.

## Использование Flexbox и Grid

- Flexbox для основного меню: выравнивание по центру, перенос пунктов и промежутки через `gap`.
- Flexbox для внутренней структуры карточек: содержимое расположено вертикально, кнопка прижата к нижней части карточки.
- CSS Grid для сетки карточек на главной странице и в каталоге: три равные колонки.
- CSS Grid для страницы каталога: колонка фильтров шириной 260px и область товаров с именованными областями `filters` и `products`.
- CSS Grid для промежутков между группами полей формы фильтров.

Форма фильтров демонстрирует HTML/CSS-вёрстку. Отбор товаров по категории и цене в практической работе 6 не реализуется.

## БЭМ-структура проекта

- `site-header` — шапка; `site-header__inner` — контейнер; `site-header__logo` — логотип.
- `site-nav` — навигация; элементы `__list`, `__item`, `__link`; `site-nav__link--active` — текущая страница.
- `site-main` — основная область страницы.
- `hero` — первый экран; элементы `__title`, `__description`, `__button`.
- `section` — раздел страницы; элементы `__title`, `__description`.
- `advantages` — список преимуществ; `advantages__item` — пункт.
- `products-grid` — сетка товаров.
- `product-card` — карточка; элементы `__title`, `__description`, `__price`, `__button`.
- `catalog-layout` — макет каталога; элементы `__products`, `__title`.
- `catalog-filters` — фильтры; элементы `__title`, `__form`, `__group`, `__legend`, `__label`, `__input`, `__checkbox`.
- `breadcrumbs` — хлебные крошки; элементы `__link`, `__current`.
- `student-info` — информация для студентов; элементы `__title`, `__description`.
- `order-dialog` — модальное окно; `order-dialog__title` — заголовок.
- `order-form` — форма; элементы `__field`, `__label`, `__input`, `__select`, `__textarea`, `__checkbox`, `__hint`, `__actions`.
- `success-message` — сообщение об успешной отправке.
- `button` — кнопка; модификаторы `button--primary`, `button--secondary`, `button--disabled`.
- `site-footer` — подвал; `site-footer__text` — текст.

Модификатор используется вместе с основным классом. Выделенная карточка на главной имеет `product-card product-card--featured`. Для будущих товаров со скидкой подготовлен `product-card--discount`; текущие цены и данные товаров сохранены. Ошибки формы используют `order-form__input--error`, `order-form__select--error`, `order-form__textarea--error` и `order-form__checkbox--error`.

Блок `button` смешивается с элементом `product-card__button`: первый отвечает за оформление кнопки, второй — за её положение в карточке. Форма `order-form` остаётся самостоятельным блоком внутри `order-dialog`.

Идентификаторы сохранены для якорей, JavaScript, подписей полей и доступности. CSS оформляет компоненты через классы, без селекторов по `id` и inline-стилей. Базовые правила для `body`, ссылок и сброса размеров остаются общими.

## Итоговая доработка КР №1

Учебная витрина одежды в эстетике starboy. Шесть согласованных вещей: чёрные джинсы, бордовая куртка, кремовое поло, серые брюки, фактурный свитер и белая рубашка. Используется исходный логотип `images/preview.jpg`.

Самостоятельные дополнения:
- Страница товара с описанием, ценой, таблицей характеристик.
- Отдельная страница заявки и модальные формы на главной, в каталоге и на странице товара.
- Выбор размера; выбранный товар отображается в форме.
- Раздел доставки и возврата и простой список преимуществ.
- Бейджи карточек через `position: relative` / `absolute`, закреплённая шапка через `sticky`, кнопка «Наверх» через `fixed` и слои `z-index`.
- Видимые состояния фокуса, подписи полей, таблицы с `caption` и заголовками `scope`.
- Базовая перестройка сеток для узких экранов.

### Запуск и проверка

Открыть `index.html` в браузере или запустить статический сервер в корне проекта. Сборка и установка пакетов не требуются.

1. Проверить меню между пятью страницами и якоря главной страницы.
2. В каталоге нажать «Подробнее о товаре»: страница должна показать выбранный товар.
3. Нажать «Заказать»: форма открывается на той же странице, выбранный товар виден в поле.
4. Проверить пустую форму, неверный email и телефон, отсутствие выбранного размера и согласия.
5. Заполнить имя, email, телефон в формате подсказки, размер и согласие: появляется сообщение об учебной проверке заявки.
6. Открыть `order.html?product=2` и проверить выбранный товар в отдельной форме; другой товар можно выбрать в списке.
7. Проверить таблицу характеристик, клавиатурный фокус и сетки на узком экране.

Формы не отправляют данные на сервер, оплата не подключена. Фильтры каталога — статическая разметка, кнопка применения отключена. Ассортимент и фотографии согласованы с автором проекта. Цены и размеры демонстрационные. Фотографии приведены к JPG 1200 × 1600, фон белый; источники указаны в `IMAGE_SOURCES.md`. Публикацию GitHub Pages необходимо проверять после загрузки финальных файлов в репозиторий.

Карточка бордовой куртки отмечена бейджем «Скидка», цена выделена красным без зачёркивания. В карточках оставлены фотография, название, описание, цена и кнопки.
